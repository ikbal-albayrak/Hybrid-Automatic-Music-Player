# Hybrid-Automatic-Music-Player
Arduino ve Python tabanlı, kafe/restoranlar için geliştirilmiş otomatik müzik sistemi.

Proje Amacı: İşletmelerde müzik yönetimini otomatize etmek.
Teknik Akış: Donanım başlatma, ses seviyesi ayarı ve sürekli döngü mantığı.
Kullanılan Kütüphaneler: Python için pygame, Arduino için DFRobotDFPlayerMini
